# BorderLens

BorderLens 是一个多身份、多证件、逐段行程的旅行入境准备 Agent。它不把“国籍 + 目的地”简化成一句免签判断，而是把出发、转机、目的地和返程拆成边境节点，再告诉用户每一段应携带、应办理和仍需核验的事项。

## 当前 MVP

- 支持香港特区护照、澳门特区护照、中国普通护照与其他证件入口；
- 支持香港、澳门、中国内地、日本、英国及其他地区的逐段路线；
- 内置三条可演示的真实场景；
- 每个结论附官方来源与核验日期；
- 规则未覆盖、口岸条件不明确或转机是否入境未知时，强制输出 `REVIEW`；
- 本地规则计算，不调用付费 OpenAI API，不收集护照号码或证件图片。

## 运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run lint
npm run build
```

## 产品边界

这是出发前预检，不是政府或航空公司的决定系统，不保证登机或入境。首版只对 `docs/RULES_AND_SOURCES.md` 中列明的窄规则给出受控结论，其他情况路由到官方核验。

完整学习过程见 `docs/BUILD_LOG.md`。

## 全球数据库阶段

Phase 26 已加入联合国 M49 全球法域目录、81 个官方/国际来源入口、143 条结构化路线（117 条已核验、26 条明确保留为 `REVIEW`）、D1/SQLite 九表数据模型、Drizzle 迁移和 `/coverage` 覆盖率控制台。当前覆盖东亚、欧洲、北美、澳新、东南亚、南亚、中东、土耳其、埃及、约旦、越南、菲律宾、蒙古、墨西哥、巴西、秘鲁、哥斯达黎加、哥伦比亚、智利、阿根廷、乌拉圭、厄瓜多尔、巴拉圭和玻利维亚的多类中国及港澳旅行证件场景；真实范围与扩展方法见 `docs/GLOBAL_DATABASE_PLAN.md`。
