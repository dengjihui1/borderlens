# BorderLens

![Jihui](assets/brand/jihui-wordmark.png)

BorderLens 是一个多身份、多证件、逐段行程的旅行入境准备 Agent。它不把“国籍 + 目的地”简化成一句免签判断，而是把出发、转机、目的地和返程拆成边境节点，再告诉用户每一段应携带、应办理和仍需核验的事项。

## 当前 MVP

- 完整规则查询入口为 `/policies`，可按实际证件、目的地、用途、交通方式和状态筛选全部 147 条记录；
- `/` 为接通全部种子库的逐段行程自查：1–8 个节点，每段单独选择证件、日期、交通、用途、入境/空侧及访问/返境依据；
- 返程及返程转机必须显式添加；口岸备注不是已验证资格，第三国签证/居留不自动认定满足条件；
- 每段生成当前官方规则、全部条件和自查待办；超出复核窗口隐藏结论，空侧转机及居民/公民返境保留 REVIEW；
- 自查勾选仅保留当前页面，可打印；不把勾选当通关许可，不输出全程 READY；旧版演示移至 `/demo`；
- 支持香港特区护照、澳门特区护照、中国普通护照与其他证件入口；
- 支持香港、澳门、中国内地、日本、英国及其他地区的逐段路线；
- 内置三组可编辑行程示例，不预先认定用户符合个人资格；
- 每个结论附官方来源与核验日期；
- 规则未覆盖、口岸条件不明确或转机是否入境未知时，强制输出 `REVIEW`；
- 行程在当前浏览器内存计算，刷新清空，不写入 URL、本地存储或服务器；不调用付费 OpenAI API，不收集护照号码或证件图片。

## 运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run lint
npm run build
```

完整质量门禁：`npm run check`。复核队列：`npm run data:review`（可追加 `-- 2026-10-21` 固定日期重放）。GitHub Actions 在 push / PR 时运行相同质量门禁。构建后启动本地 Worker，再运行 `npm run smoke -- http://127.0.0.1:4179` 可复现 26 项 HTTP 页面验收；该命令拒绝生产域名，避免绕过站点认证。

统筹后的范围、验收和未完成项见 [项目交付计划](docs/PROJECT_PLAN.md)。证据核验有效不等于个人已满足全部条件，也不等于通关许可。

## 产品边界

这是出发前预检，不是政府或航空公司的决定系统，不保证登机或入境。首版只对 `docs/RULES_AND_SOURCES.md` 中列明的窄规则给出受控结论，其他情况路由到官方核验。

完整学习过程见 `docs/BUILD_LOG.md`。
