# BorderLens

![Jihui](assets/brand/jihui-wordmark.png)

BorderLens 是一个多身份、多证件、逐段行程的旅行入境准备 Agent。它不把“国籍 + 目的地”简化成一句免签判断，而是把出发、转机、目的地和返程拆成边境节点，再告诉用户每一段应携带、应办理和仍需核验的事项。

## 当前 MVP

- 完整规则查询入口为 `/policies`，可按实际证件、目的地、用途、交通方式和状态筛选全部 143 条记录；
- `/` 仍为早期逐段行程演示，范围和核验日期独立，不能代表数据库的完整查询能力；
- 支持香港特区护照、澳门特区护照、中国普通护照与其他证件入口；
- 支持香港、澳门、中国内地、日本、英国及其他地区的逐段路线；
- 内置三条可演示的真实场景；
- 每个结论附官方来源与核验日期；
- 规则未覆盖、口岸条件不明确或转机是否入境未知时，强制输出 `REVIEW`；
- 本地规则计算，不调用付费 OpenAI API，不收集护照号码或证件图片。

## 运行

```bash
npm install
npm run dev
```

验证：

```bash
npm test
npm run lint
npm run build
```

完整质量门禁：`npm run check`。复核队列：`npm run data:review`（可追加 `-- 2026-10-21` 固定日期重放）。GitHub Actions 在 push / PR 时运行相同质量门禁。构建后启动本地 Worker，再运行 `npm run smoke -- http://127.0.0.1:4179` 可复现 16 项 HTTP 页面验收；该命令拒绝生产域名，避免绕过站点认证。

统筹后的范围、验收和未完成项见 [项目交付计划](docs/PROJECT_PLAN.md)。证据核验有效不等于个人已满足全部条件，也不等于通关许可。

## 产品边界

这是出发前预检，不是政府或航空公司的决定系统，不保证登机或入境。首版只对 `docs/RULES_AND_SOURCES.md` 中列明的窄规则给出受控结论，其他情况路由到官方核验。

完整学习过程见 `docs/BUILD_LOG.md`。

## 全球数据库阶段

Phase 70 依据当前阿曼外交部、Visit Qatar 精确条件分支及国家移民管理局原文复核 8 条路线；阿曼中国及港澳普通护照更正为有条件 14 天免签，卡塔尔 A1-3 更正为免签或可选 Hayya A1。数据仍为 248 个 M49 法域、109 个官方/国际来源入口、143 条结构化路线。2026-10-21 有 85 条有效证据（其中 1 条个体条件需人工核验）、55 条历史到期、3 条明确证据问题；查询为 84 条当前结论、59 条 REVIEW。未访问成功或证据不足的路线不续期。原文和缺口见 `docs/REVALIDATION_LOG.md`。
