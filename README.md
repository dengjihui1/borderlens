# BorderLens

![Jihui](assets/brand/jihui-wordmark.png)

BorderLens 是一个多身份、多证件、逐段行程的旅行入境准备 Agent。它不把“国籍 + 目的地”简化成一句免签判断，而是把出发、转机、目的地和返程拆成边境节点，再告诉用户每一段应携带、应办理和仍需核验的事项。

## 当前 MVP

- 支持香港特区护照、澳门特区护照、中国普通护照与其他证件入口；
- 支持香港、澳门、中国内地、日本、英国及其他地区的逐段路线；
- 内置三条可演示的真实场景；
- 每个结论附官方来源与核验日期；
- 规则未覆盖、口岸条件不明确或转机是否入境未知时，强制输出 `REVIEW`；
- 本地规则计算，不调用付费 OpenAI API，不收集护照号码或证件图片。


```bash

```

## 产品边界

这是出发前预检，不是政府或航空公司的决定系统，不保证登机或入境。首版只对 `docs/RULES_AND_SOURCES.md` 中列明的窄规则给出受控结论，其他情况路由到官方核验。

完整学习过程见 `docs/BUILD_LOG.md`。

## 全球数据库阶段

Phase 65 已建立联合国 M49 全球法域目录、102 个官方/国际来源入口、143 条结构化路线，并新增“复核到期即按当前有效性计入 REVIEW”的门禁。2026-10-21 已重新核验日本、新西兰、申根、新加坡、土耳其、泰国、马来西亚、斯里兰卡、马尔代夫、文莱、蒙古、乌拉圭、厄瓜多尔、埃及和菲律宾十五组官方来源，对应 46 条规则当前有效；其余库内规则保留原始证据，但超过复核窗口后不再被 `/coverage` 或产品结果当作当前有效。项目仍覆盖东亚、欧洲、北美、澳新、东南亚、南亚、中东及拉美的多类中国、香港和澳门旅行证件场景；证据不足、官方入口失效或期限未明确的路线继续保留 `REVIEW`，搜索摘要不冒充生产证据。真实范围、当前有效性和扩展方法见 `docs/GLOBAL_DATABASE_PLAN.md` 与 `docs/REVALIDATION_LOG.md`。
