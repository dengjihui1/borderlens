# BorderLens

![Jihui](assets/brand/jihui-wordmark.png)

BorderLens 是一个多身份、多证件、逐段行程的旅行入境准备 Agent。它不把“国籍 + 目的地”简化成一句免签判断，而是把出发、转机、目的地和返程拆成边境节点，再告诉用户每一段应携带、应办理和仍需核验的事项。

## 当前 MVP

- 支持香港特区护照、澳门特区护照、中国普通护照与其他证件入口；
- 支持香港、澳门、中国内地、日本、英国及其他地区的逐段路线；
- 内置三条可演示的真实场景；
- 每个结论附官方来源与核验日期；
- 规则未覆盖、口岸条件不明确或转机是否入境未知时，强制输出 `REVIEW`；
- 本地规则计算，不调用付费 OpenAI API，不收集护照号码或证件图片。

## 产品边界

这是出发前预检，不是政府或航空公司的决定系统，不保证登机或入境。首版只对 `docs/RULES_AND_SOURCES.md` 中列明的窄规则给出受控结论，其他情况路由到官方核验。

完整学习过程见 `docs/BUILD_LOG.md`。

## 全球数据库阶段

Phase 66 已建立联合国 M49 全球法域目录、102 个官方/国际来源入口、143 条结构化路线。2026-10-21 当前有效 57 条，另有 86 条历史规则因复核到期进入 REVIEW。本批从英国官方问答、加拿大 IRCC 入境要求和东帝汶移民局旅游签证及豁免页续期 11 条规则，并补全身份、交通方式和资金边界。老挝已修复官方资格页链接，但申请资格本身不足以证明必须办签；柬埔寨和缅甸仍缺少本批可完整核验的政策正文，均未续期。`/coverage` 的数量和卡片结论共同受时效门禁约束，过期或混合批次不展示旧的整组确定性结论。真实范围、当前有效性、来源定位和未解决项见 `docs/GLOBAL_DATABASE_PLAN.md` 与 `docs/REVALIDATION_LOG.md`。
