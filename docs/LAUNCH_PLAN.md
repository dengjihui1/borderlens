# BorderLens 上线与海内外宣发计划

状态：私有预发布。用户验收前，不改公开访问范围，也不对外发帖。本文只规划执行顺序，不代表政策、法务或市场验证已经完成。

## 定位与承诺边界

面向持多种旅行证件、需要处理转机和返程的旅客，提供“实际证件 × 逐段行程”的只读自查清单，以及可追溯的官方来源入口。不是签证代办、资格裁定或入境许可。全球法域目录不等于全球规则覆盖；当前仅有受控的窄规则，缺失或冲突进入 REVIEW。

公开文案不得使用“全球签证规则全覆盖”“保证免签/登机/入境”“填完即通过”“AI 自动给出实时签证结论”。中英文均须清楚展示：条件必须逐条核对官方来源；REVIEW 不输出确定结论；签证申请、出境、承运人、口岸和个人资格另行核验。英文版的政策条件保留原文，不能宣传为已完成法律性全量翻译。

## 公开前门槛（逐项打勾）

1. 代码：`npm run check`、本地 Worker `npm run smoke`、中英文浏览器端的语言切换、筛选、示例、REVIEW、空态、打印、窄屏和链接均通过；GitHub CI 对最终 SHA 绿灯。
2. 数据：`npm run data:review` 留存当日结果；逐条记录即将到期规则的复核责任与日期。当前 5 条 REVIEW 不为发布而强行清零。公开前对优先宣传的路线重新核读官方页面，尤其是来源受阻或有冲突的记录。
3. 内容：中英文标题、描述、隐私说明、使用边界及支持入口互相一致；只宣传已受控证件与路线。英文原文条件提示在具体结果上可见。
4. 隐私与运营：确认无行程/证件输入上报、无个人信息日志；准备问题反馈入口、纠错处理人、回滚方法与政策更新频率。若增加分析工具，先做单独隐私审核。
5. 发布：先确认私有版本与 GitHub SHA 一致；由用户完成产品验收并明确同意公开访问后再切换权限。公开后再跑一次生产页面与权限检查。

## 宣发顺序

| 阶段 | 动作 | 验收指标 |
| --- | --- | --- |
| 私有内测 | 邀请少量旅行者和熟悉签证政策的审校者，以指定路线测试证件选择、转机、返程、REVIEW 可理解性；记录问题，不接收证件照片或号码 | 关键流程完成率、误解率、政策纠错响应时间 |
| 小范围公开 | 发布一页中英双语使用说明和两段 30–60 秒屏幕演示；只展示可公开且近期复核的示例；落地页直接进入工具 | 点击到完成首次自查、官方来源点击率、REVIEW 理解率 |
| 持续内容 | 每周用“实际证件 + 口岸 + 日期 + 官方来源”的格式做案例型内容；政策变更先核验再更新站内与内容 | 有效回访、来源纠错闭环、过期内容撤回时长 |

国内优先渠道：小红书图文/短视频、B 站操作演示、微信公众号或知乎的证件差异说明。海外优先渠道：英文短视频（YouTube Shorts / Instagram Reels）、Reddit 相关旅行讨论区的合规答疑、Product Hunt 的工具说明；先查看各社区自推规则，避免群发。不要把示例路线当对所有国籍或证件都有效。

每条内容统一结构：一个具体旅程场景 → 用户在工具里如何逐段选证件 → 哪些结论仍是 REVIEW / 原文条件 → 官方来源链接 → “出发前重新核验”提示。避免诱导用户提交护照号、照片或私人行程。

## 可复用文案草稿（公开前须随当日规则重审）

中文：`BorderLens 帮你按实际旅行证件逐段整理出发、转机与返程的入境自查事项。只显示有受控官方证据的规则；条件和来源需要出发前逐条核对。它不代办签证，也不保证登机或入境。`

English: `BorderLens helps you check entry-rule evidence one border at a time, using the travel document you will actually carry. Review every original condition and official source before travel. It does not issue visas or guarantee boarding or entry.`
