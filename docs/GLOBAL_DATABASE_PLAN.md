# 全球签证政策数据库方案

状态：Phase 29 Brunei ordinary-passport route，2026-09-11。

## 1. “全球覆盖”到底有多大

联合国 M49 当前目录生成了 248 个国家与地区。即使只考虑：

- 248 个目的地；
- 248 个证件签发地；
- 7 类旅行目的；

也至少产生 430,528 个组合，还没有计算普通/公务/外交/特殊护照、居留资格、转机是否入境、航空/陆路/海路、口岸差异和生效日期。因此本项目不会承诺通过人工一次性填完“全球免签表”。

## 2. 四层覆盖模型

1. **Jurisdiction cataloged**：国家/地区存在于联合国 M49 主目录；
2. **Official source discovered**：已找到主管政府或国际组织入口；
3. **Rule structured**：已把官方原文转成证件、目的、口岸、结果和条件；
4. **Rule verified**：证据定位、日期、冲突检查与回归测试通过。

只有第 4 层可以让用户看到明确政策结论。第 1–3 层仍应输出 `REVIEW`。

## 3. 数据表

| 表 | 作用 |
|---|---|
| `jurisdictions` | 联合国 M49 国家与地区主目录 |
| `official_sources` | 政府、移民部门、官方检查器和 IATA 来源注册表 |
| `travel_documents` | 普通、特殊、公务、外交护照及居留/通行证 |
| `policy_zones` | 申根等不能伪装成单一国家代码的跨境政策区域 |
| `policy_zone_members` | 政策区域到成员法域的可复核映射 |
| `policy_rules` | 目的地 × 证件签发地 × 目的 × 口岸方式的结构化结论 |
| `rule_sources` | 规则到官方证据、段落、抓取时间和内容哈希的连接 |
| `review_queue` | 新来源、过期、冲突、用户纠正和未支持路线的审核队列 |
| `ingestion_runs` | 每次采集的成功、拒绝与错误统计 |

数据库模式见 `db/schema.ts`，生成的不可变迁移见 `drizzle/`。`policy_rules` 强制要求“单一目的地法域”与“政策区域”二选一，防止把申根错误写成国家。

## 4. 来源优先级

1. 目的地政府、移民局、外交部、驻外使领馆；
2. 超国家官方系统，例如欧盟委员会的申根签证政策；
3. IATA Timatic 等用于航空公司登机检查的许可数据；
4. 第三方聚合器只用于发现线索，不能直接生成“已验证”规则。

维基百科、博客、旅行社页面、论坛和模型记忆不能作为政策事实源。

## 5. 采集流程

```text
发现官方入口
  → 保存原文定位与日期
  → 结构化候选规则（draft）
  → 与现有规则做冲突检查
  → 人工或双源复核
  → 回归测试
  → verified
  → 到期或来源变化后自动 stale
```

自动化只能生成 `draft`。发布为 `verified` 必须有官方来源和明确的适用边界。

## 6. 当前真实覆盖

- 248 个联合国 M49 国家与地区已进入目录；
- 82 个官方或国际来源入口已注册，其中 68 个已支撑至少一条核验规则；
- 143 条规则已结构化为种子数据：118 条已核验，25 条明确保留为 `draft/REVIEW`；文莱外交部当前路由器和 D3 页面核验中国普通护照免签最多 14 天；尼泊尔 Visa Exemption 页面仅能支撑外交及官方/服务护照范围，不能推出中国普通护照旅游免签，三类目标证件路线均保留待复核；
- 新西兰、申根、新加坡、澳大利亚、英国、韩国、阿联酋、美国、加拿大、泰国、马来西亚、印度尼西亚、柬埔寨、老挝、缅甸、文莱、东帝汶、斯里兰卡、马尔代夫、土耳其和埃及已完成目标证件的第一轮窄规则采集；
- 申根被建模为 1 个政策区域，当前包含 29 个成员法域；
- 中国内地新增非中国籍香港/澳门永久居民专用通行证规则，并继续保留中国籍居民回乡证路线的人工口岸核验；
- 美国国务院与加拿大旧版动态检查器仍受阻，但已改用同一政府体系内可访问的 CBP、DHS 与 Canada.ca/IRCC 页面完成目标规则核验；原受阻入口不伪装为已恢复。
- 越南新官方电子签页面及公开 API 已恢复可审阅：国籍 API 将 CHN / China 标为 EVISA，官方页面及 API 内容给出最长 90 天、单次或多次入境、境外申请、有效护照或国际旅行证件和指定国际口岸条件；HKG/MAC 仍无独立记录，不能从名单缺席推出完整结论。菲律宾外交部页面仍停在 Cloudflare 安全验证，但移民局 Visa Waiver 页面已直接核验港澳特区护照 9A 免签、初始准许停留 14 天，中国普通护照继续 `draft/REVIEW`。蒙古电子签官方系统的 VISA FREE COUNTRIES 名单同时列出中国、香港特区和澳门特区；由于该页没有期限和特殊旅行证件细分，三条路线均不补填停留天数。乌拉圭内政部官方签证制度表进一步直接核验中国普通护照需签证及其条件例外、香港特区护照免签和澳门特区护照免签，三条均不补填表格未明确的停留期限。尼泊尔移民局 Visa Exemption 页面明确该免签表仅适用于外交及官方/服务护照；中国普通护照、香港与澳门特区护照旅游路线不能据此推出结论，继续 REVIEW。
- 第五批把电子签、落地签和免签拆成不同路线：柬埔寨 Visa T、老挝 T-B3、缅甸 Tourist eVisa、文莱 D3 免签与东帝汶落地签均保存期限、证件和口岸边界；第二十九批复核文莱当前国家路由器，确认 China > Ordinary Passport 直接进入 D3，补齐中国普通护照最多 14 天免签路线。
- 第六批新增南亚五国：斯里兰卡与马尔代夫共 6 条目标证件路线已核验；印度 eVisa 名单缺少目标证件、尼泊尔旧落地签页 404、孟加拉国 MRV 入口缺少国籍结果，因此当时 9 条路线保留为 `draft/REVIEW`。第二十七批曾误读尼泊尔免签表的证件范围；第二十八批已按页面标题和正文纠正为外交及官方/服务护照证据，三类目标旅游路线均继续 REVIEW。
- 第七批新增中东五国：卡塔尔、沙特和巴林共 9 条路线已核验；阿曼与约旦因官方页面不足以证明完整签证结论，6 条路线保留为 `draft/REVIEW`。

## 7. 扩展顺序

按“用户需求量 × 官方数据可获得性 × 规则稳定性”推进：

1. 日本、英国、申根、美国、加拿大、澳大利亚、新西兰；
2. 中国内地、香港、澳门、新加坡、韩国、阿联酋；
3. 东南亚、拉美、中东其他高频目的地；
4. 其余法域与特殊证件；
5. 最后才是航空公司、特定口岸和复杂过境例外。

## 8. 商业级数据的现实边界

IATA Timatic 是航空业的重要标准，但属于许可型产品。BorderLens 不能未经许可复制其完整数据库。若未来商业化，应购买合法数据授权或与合规数据提供商合作；公开官方页面则要分别处理抓取频率、使用条款、页面变更和人工复核。
